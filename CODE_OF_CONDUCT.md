# Community Code of Conduct

We want this project to be useful and welcoming to people with different backgrounds and levels of
technical experience.

## Expected behavior

- Be respectful, patient, and specific.
- Discuss ideas and evidence rather than attacking people.
- Help non-specialists understand technical decisions.
- Protect customer information and use synthetic examples in public discussions.
- Accept maintainer decisions about project scope, safety, and release readiness.

Harassment, discrimination, threats, deliberate disclosure of private information, spam, and other
disruptive behavior are not accepted in project spaces.

## Reporting

For ordinary moderation concerns, email [admin@anilau.com](mailto:admin@anilau.com). Security issues
must follow [SECURITY.md](SECURITY.md). Reports will be reviewed in context, and maintainers may edit,
remove, or reject contributions or restrict participation when needed.

This policy applies to repository discussions, issues, pull requests, and other official project
spaces.
